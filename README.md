# RoutePulse

RoutePulse is a SaaS fleet intelligence platform for small–medium logistics & delivery companies.

## Target users

1. **Operations / Fleet Managers**
- They manage drivers, vehicles, deliveries
- They care about delays, fuel cost, misuse, inefficiency

2. **Dispatchers**
- Assign jobs
- Monitor live vehicle locations
- React to delays/incidents

3. **Business Owners**
- Want reports, cost breakdowns, performance metrics
- Don’t care about tech details
